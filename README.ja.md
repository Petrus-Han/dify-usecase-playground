## プロジェクト概要

**Dify Use Case Playground** は、実用的な Dify ワークフロー DSL の例とユースケースを収集する個人のオープンソースリポジトリです。このリポジトリは、Dify のワークフローエンジンを使用して本番環境に対応したワークフローを構築するための学習リソースとリファレンスとして機能します。

## 内容

このリポジトリには以下が含まれます：

- 📋 **ワークフロー DSL ファイル** (`.yml`) - Dify にインポートできる完全なワークフロー定義
- 📖 **ドキュメント** (`README.md`) - 各ユースケースの詳細な説明
- 🎨 **ベストプラクティス** - 実世界のパターンとソリューション

## 機能

- ✅ 本番環境対応のワークフロー
- ✅ 包括的なドキュメント
- ✅ インポートとカスタマイズが容易
- ✅ 実世界のユースケース
- ✅ ベストプラクティスとパターン
- 🔒 **セキュリティ**: CI/CD による自動化されたシークレットスキャン

## ユースケース

### 🤖 自動化

- **[Slack チャンネルへの日次ニュース](./usecases/daily-news-slack/)** - スケジュールトリガーを使用して Slack チャンネルに日次ニュースを自動配信

### 💬 チャットボットとアシスタント

- **[Slack トリガーニュースリサーチャー](./usecases/slack-news-researcher/)** - 質問分類とニュースリサーチ機能を備えたインテリジェントな Slack ボット

## はじめに

1. **ユースケースを閲覧**
   - `usecases/` ディレクトリを探索
   - 各ユースケースには `workflow.yml` と `README.md` を含む独自のフォルダがあります

2. **ワークフローをインポート**
   - Dify コンソールを開く
   - ユースケースフォルダから `.yml` ファイルをインポート
   - ユースケース README のセットアップ手順に従う

3. **カスタマイズ**
   - ニーズに応じてワークフローを変更
   - 設定パラメータを更新
   - テストしてデプロイ

## セキュリティ

🔒 **このリポジトリは自動化されたシークレットスキャンを使用**して、機密情報の誤ったコミットを防ぎます：

- **CI/CD 統合**: GitHub Actions ワークフローがすべてのプッシュとプルリクエストで自動的にシークレットをスキャン
- **使用ツール**: 
  - [Gitleaks](https://github.com/gitleaks/gitleaks) - 包括的なシークレット検出
  - 一般的な機密データのカスタムパターンマッチング
- **チェック内容**: API キー、トークン、パスワード、Webhook URL、AWS キー、Slack トークンなど

**重要**: API キー、トークン、または認証情報などの機密情報をコミットしないでください。代わりに環境変数または安全な設定管理を使用してください。

## コード言語ポリシー

🌐 **このプロジェクトは国際的なポジショニングを維持しています。**

- ✅ **コードファイルには中国語またはその他の言語を含めることができます** - 国際化（i18n）サポートのために推奨
- ✅ Dify ワークフローファイルの i18n フィールド（`zh_Hans`, `zh_Hant`, `ja_JP`, `pt_BR` など）は完全にサポートされています
- ✅ **Git コミットメッセージは英語でなければなりません** - 国際的なプロジェクトポジショニングを維持するため
- ✅ **プルリクエストのタイトルと説明は英語でなければなりません** - グローバルなコラボレーションのため
- 📖 ドキュメントファイルは複数の言語で利用可能（英語、簡体字中国語、繁体字中国語、日本語）

**注意**: CI チェックは git コミットメッセージと PR コンテンツに英語を強制しますが、国際化の目的でコードファイル内の任意の言語を許可します。
